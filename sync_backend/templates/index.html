Shortcuts

Desktop-style bindings in web studio:

  • S: select mode
  • W: draw mode
  • B/O: bbox / obb draw shape
  • Arrow Left/Right or A/D/Space: prev/next image
  • Delete/Backspace: delete selected label
  • Ctrl/Cmd+Z, Ctrl/Cmd+Y: undo/redo
  • Q/E/R: rotate selected box counterclockwise / clockwise / 180
  • +/-: zoom in / zoom out, 0: fit to stage
  • Ctrl/Cmd+S: save labels
  • L: toggle label overlay
  • Esc: cancel draw / clear selection
